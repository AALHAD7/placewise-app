# PlaceWise — Full-site QA pass

**Date:** 2026-11-02
**Target:** Production — frontend `https://placewise-io.vercel.app`, backend
`https://placement-mastery-hub-api.onrender.com`
**Mode:** Report-only (`/qa-only`) — no fixes applied, no product code/config changed.
**Method:** gstack's own headless browser (`gstack/browse`; Aside was not available on this
machine, so no personal logins/cookies were used) driving a fresh Guest session, plus direct
`curl` calls to confirm API response bodies. Screenshots in `qa/screenshots/`.
**Trigger:** systematic re-test of every route after the Guesstimates "random pick showed the
casebook's table-of-contents page" bug (see `log.md`, two 2026-11-02 entries), to check whether
other features have a similar "looks right until a real user clicks it" problem.

**Overall verdict:** No repeat of the Guesstimates-class bug was found elsewhere, and the core
AI flows (Mock Interview, Resume Drill, Role chip panels, Tone Shifter, admin access control)
are solid end-to-end. But the Frameworks page has a real, same-class problem — a "from the
casebooks" list polluted with non-framework boilerplate (team rosters, "Do's/Don'ts", raw
data labels) styled as clickable content — plus one framework card (MECE) and the Skill page's
Core Concepts silently skip the grounding citation/label the policy requires. Severity:
**medium** overall — nothing crashes or leaks data, but the Frameworks findings go to the same
trust problem the Guesstimates bug did (content that looks grounded/curated but isn't).

## Notes on scope and method

- Aside (the user's real signed-in browser) was unavailable on this machine, so all testing
  used a synthetic Guest session via gstack's own headless browser, plus direct `curl` calls
  to the production API for response-body verification. No real user credentials or Google
  OAuth were tested end-to-end (that flow was visible/clickable but not exercised, to avoid
  touching a real account).
- AI-generation calls were kept to a handful of representative inputs per feature (one mock
  interview question + answer, one resume-question generation, one tone-shift, one chip-panel
  expansion, a few framework "Review" expansions) rather than exhaustive sweeps, per the cost
  guidance in the task.
- Cosmetic font-preload console warnings (`fonts.gstatic.com ... preloaded ... but not used`)
  appear on every page. Not filed as a bug — purely a resource-hint tuning issue, no functional
  impact, not related to the grounding/content-correctness scope of this pass.
