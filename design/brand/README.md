# PlaceWise logo assets

This pack follows the supplied reference with a complete blue P, a simplified orange rising arrow, and a side-by-side horizontal lockup.

- `placewise-logo.svg` — horizontal lockup with the emblem, wordmark, and tagline; transparent background.
- `placewise-icon.svg` — standalone app icon on a dark rounded square.
- `placewise-mark.svg` — transparent standalone emblem; use at 32 × 32 px for a favicon.
- `placewise-preview.svg` — dark presentation sheet showing the logo and icon together.

## Brand colors

- Electric orange: `#FF6B35`
- Royal blue: `#2563EB`
- Obsidian: `#0A0D14`
- White: `#FFFFFF`

SVG geometry is built from editable vector paths and has no gradients, shadows, or raster embeds. The wordmark and tagline use live SVG text. The font stack starts with Inter and falls back to system sans-serif fonts; convert the text to paths in a vector editor if you need identical typography across systems. The logo and standalone mark have transparent backgrounds, while the app icon and preview sheet include the dark background. Use the standalone mark at 32 × 32 px; for 16 × 16 px, use a simplified arrow-only glyph to preserve detail.
